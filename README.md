## Запуск

```bash
cp .env.example .env        # если .env ещё нет; задайте пароль Postgres
docker compose up -d --build
```

Первый запуск долгий: собирается jar и контейнер `ollama-pull` скачивает модель (файл весов около 6 ГБ).
Следить за загрузкой: `docker compose logs -f ollama-pull`.

Когда `http://localhost/api/health` отвечает `"status":"up"` — открывайте `http://localhost`.

Нужна видеокарта NVIDIA от 6 ГБ и NVIDIA Container Toolkit (на Windows — через WSL2). Без GPU уберите блок
`deploy:` у сервиса `ollama` в `docker-compose.yaml` — модель пойдёт на CPU, медленно.

## Запуск без Docker (разработка)

Профиль `memory` хранит данные в памяти, Postgres не нужен. Ollama должна быть запущена локально
(`ollama pull gemma4:e4b-it-qat`).

```bash
./gradlew bootRun --args='--spring.profiles.active=memory'
# http://localhost:8080
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | состояние Ollama, хранилища и LanguageTool; 503, если что-то не отвечает |
| GET | `/api/errors` | журнал ошибок: правило, пример, сколько раз |
| GET | `/api/review` | карточки правил, которые пора повторить сегодня |
| POST | `/api/review/{slug}` | оценка повторения `{rating: 1..4}` — снова, трудно, хорошо, легко |
| GET / PUT | `/api/profile` | профиль: имя, уровень CEFR |
| POST | `/api/sessions` | начать урок `{cefr?, topic?, mode?}` |
| GET | `/api/sessions`, `/api/sessions/{id}` | последние уроки / один урок |
| GET | `/api/sessions/{id}/messages` | история урока |
| PUT | `/api/sessions/{id}/level` | сменить уровень урока `{cefr}` |
| POST | `/api/sessions/{id}/end` | завершить урок |
| POST | `/api/chat` | ход урока `{sessionId, text?, hint?}`, ответ — SSE (`delta`, `final`, `error`) |
| POST | `/api/audio/stt` | «нажми и скажи»: файл записи → `{text}` |
| POST | `/api/audio/tts` | озвучка английской реплики `{text}` → WAV |
| GET | `/api/export/anki` | CSV для Anki (`?scope=fsrs|due|catalog`) |
| GET | `/api/scenarios` | список ролевых сценариев |
| GET | `/api/scenarios/sessions/{id}` | чеклист целей сценария в уроке |
| WS | `/ws/voice` | дуплекс: PCM 16 kHz в binary, управление и ответы в JSON (см. ниже) |

Режимы урока: `conversation`, `explain`, `correct`, `drill`, `roleplay` (сценарий в `topic` — slug из `/api/scenarios`), `structured` (guided lesson).

**Guided lesson (`structured`):** при старте передайте `durationMin`: **15** или **25**. В одном чате четыре фазы по таймеру: warm-up → input → practice → feedback. В ответах сессии и в SSE `final` — поля `lessonPhase`, `phaseLabel`, `minutesRemaining`, `targetMinutes`. Состояние в `sessions.plan_state`.

## Как решается, что показать в «Исправлении»

1. Реплику ученика сначала проверяет LanguageTool. Его находки показываются всегда и передаются модели как факты.
2. Исправление от самой модели принимается, только если она указала ошибочный фрагмент дословно из текста ученика
   и действительно его изменила. Укороченная или пересказанная фраза исправлением не считается.
3. Всё, что прошло, попадает в журнал ошибок (`error_events`).

Логика — в `session/CorrectionPolicy.java`, тесты — в `CorrectionPolicyTest`.
Если LanguageTool недоступен, урок продолжается без него, а `/api/health` показывает `down`.

## Карточки правил и повторение

Короткие заметки лежат в `src/main/resources/rules/`. Это свои формулировки: правило, верный пример, неверный и типичная ошибка русскоязычных. Когда LanguageTool находит ошибку или ученик спрашивает про правило, в запрос модели кладётся одна-две карточки, а ученик видит текст карточки, а не выдуманное правило.

Поиск по словам и по id LanguageTool работает всегда. Поиск по смыслу — сервис `embed` (paraphrase-multilingual-MiniLM-L12-v2, только процессор). Он нужен, чтобы фраза вроде «когда писать have been» нашла карточку с другим названием. Если сервис ещё не поднялся, урок идёт без него.

Ошибка, к которой нашлась карточка, ставится в очередь FSRS. Вкладка «Повторение» показывает, сколько карточек пора повторить сегодня. Оценки: снова, трудно, хорошо, легко.

## Нажми и скажи

В уроке кнопка «Говорить». Короткое нажатие включает микрофон, повторное отправляет фразу. Если кнопку удерживать, фраза уходит, когда её отпускают. Запись не длиннее 30 секунд.

Распознавание — отдельный контейнер `stt` (faster-whisper `small`, int8, только процессор, с отсечением тишины). По умолчанию язык **английский** (`tutor.stt.language=en`); при автоопределении русскоязычная речь иногда уходит в кириллицу вроде «Вася из кот» вместо «Vasia is a cat». Текст попадает в тот же ход урока, что и набранный с клавиатуры.

## Свободный голос (шаг 7)

Чекбокс «Свободный голос» в уроке. Один канал WebSocket `/ws/voice`:

1. Клиент шлёт `{"type":"hello","sessionId":…,"mode":"handsfree"|"ptt"}`.
2. Дальше — **binary**: PCM int16 mono 16 kHz (микрофон через Web Audio).
3. Режим **без кнопки**: конец фразы по паузе на сервере (VAD); **кнопка «Говорить»** — PTT через `ptt_start` / `ptt_end`.
4. Сервер → `transcript`, стрим `delta`, `final` (как в чате), затем WAV по предложениям (`audio` + binary).
5. Если говорите поверх ответа учителя — `cancel_audio` (barge-in).

«Нажми и скажи» по REST (`/api/audio/stt`) по-прежнему работает без WebSocket.

## Озвучка ответа

У реплики учителя кнопка «Слушать». Она читает английский текст пузыря целиком, вместе со следующим вопросом. Если фраза пришла с микрофона, озвучка начинается сама; если браузер её блокирует, остаётся кнопка.

Озвучка — отдельный контейнер `tts` (Kokoro, fp16, голос `af_heart`, только процессор). Русский перевод не озвучивается. Пока контейнер качает модель, кнопка ответит, что озвучка недоступна; читать текст можно сразу.

## Как устроен код

```
src/main/java/study/ai_foreign_language_teacher/
  api/      REST-контроллеры и DTO
  session/  TurnEngine — педагогический контур одного хода; LessonService — урок и сохранение
  speech/   клиенты распознавания и озвучки
  nlp/      клиент LanguageTool (проверка грамматики до LLM)
  llm/      клиент Ollama (1 запрос за раз), промпт, JSON-схема, разбор ответа
  memory/   хранилище: jdbc/ (Postgres) и inmemory/ (профиль memory)
  domain/   CEFR, режимы, контракт ответа учителя
  config/   настройки tutor.* из application.properties
web/        интерфейс: чистый HTML/CSS/JS без сборки, раздаёт nginx
```

Основные настройки — `src/main/resources/application.properties` (`tutor.ollama.*`, `tutor.lesson.*`);
в Docker они переопределяются переменными окружения из `docker-compose.yaml`.
